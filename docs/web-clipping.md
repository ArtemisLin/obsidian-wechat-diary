# 公众号链接剪藏

把微信公众号文章链接发给 bot，插件会在本机提取正文与正文图片，保存为 Obsidian Markdown。该过程不调用 AI。

## 使用方式

- 发 `https://mp.weixin.qq.com/s/...`：原句照常写入今日日记，下一行增加剪藏文件入口。
- 发 `值得研究：https://mp.weixin.qq.com/s/...`：「值得研究」还会写入剪藏文件的「微信附言」。
- 发普通网站链接：默认只按原句记入日记，不访问该网站。
- 在设置中打开「其他网站的链接也提取正文」后，才会尝试剪藏其它公开 `http/https` 网站。
- 发 `记：https://mp.weixin.qq.com/s/...`：只把 URL 原样记进日记，不访问网页。
- 一条消息最多自动剪藏 3 个链接；无论成功或失败，原始句子都只写入一次。

「自动提取公众号正文」默认开启，「其他网站的链接也提取正文」默认关闭。「保存正文图片」默认开启，可以单独关闭。

## 写入结构

剪藏目录默认跟随日记目录，即 `<日记文件夹>/剪藏`。用户可在设置中指定其它 Vault 相对路径。

```text
日记/
├── YYYY/
│   └── YYYY-MM-DD.md
└── 剪藏/
    ├── YYYY/
    │   └── YYYY-MM-DD-标题-文章身份哈希.md
    └── assets/
        └── YYYY/
            └── YYYY-MM-DD-文章身份哈希/
                ├── 01-图片内容哈希.jpg
                └── 02-图片内容哈希.png
```

剪藏文件记录原始 URL、canonical URL、稳定身份 URL、站点、作者、发布时间、抓取时间、微信附言、正文及图片保存统计。正文图片保存到 `assets` 子目录，Markdown 使用完整 Vault 路径的 `![[...]]` 本地嵌入。

今日日记中的一个块保持以下格式：

```markdown
值得研究：https://mp.weixin.qq.com/s/...
[[日记/剪藏/2026/2026-08-29-文章标题-a1b2c3d4e5.md|🔖 文章标题]]
```

同一篇公众号文章再次发送时，会用去掉 `chksm`、`scene` 等波动参数后的稳定身份复用已有文件。早期剪藏没有图片元数据，或本次成功图片更多时，插件会保留旧文件并另建改进版，不覆盖已有笔记。「撤回」只移除日记里的整块原句与入口，不删除剪藏文件或已下载图片。

## 提取规则与限制

插件优先识别公众号 `#js_content` 以及 `article`、`main` 和常见正文容器，先移除脚本、公众号二维码/工具栏/底栏/弹窗、导航、页脚和广告，再转换标题、段落、嵌套列表、引用、代码块、表格、链接和图片。网页提供的 Obsidian 特殊语法会被转义，只有插件自己生成的剪藏入口与本地图片内链会保持可执行语法。

以下网页可能无法提取：

- 需要登录、验证码或 Cookie 才能查看；
- 付费墙之后的内容；
- HTML 中没有正文，必须运行 JavaScript 才生成内容；
- 服务器拒绝桌面客户端请求；
- 非 HTML 文件，或网页源码超过 5MB。

抓取失败时，插件仍会把原始句子写进当天日记并返回失败原因。正文默认最多保存 20 万字符，超出时会显式标注截断并保留原文链接。

图片采用尽力保存策略：单张失败不影响正文，笔记会留下可点击的原图地址与失败原因。默认每篇最多尝试 30 张、合计 50MB（设置中可调至最多 100 张/500MB），单张上限 15MB；单张下载最长 10 秒，同一时间最多下载 4 张，整篇剪藏总预算 75 秒。支持 JPEG、PNG、GIF、WebP、BMP、HEIC 和 AVIF；明显的跟踪像素会忽略。

## 网络与安全边界

只有主人白名单内的微信消息会触发剪藏。默认仅请求用户发送的 `mp.weixin.qq.com` 页面和正文内图片；其它网站必须由用户主动打开扩展开关。插件不执行网页 JavaScript，也不加载广告、iframe 或样式。页面与图片地址中的本机、局域网、link-local、IPv4-mapped IPv6 和常见私有地址都会被拒绝。

页面和图片优先通过 Obsidian `requestUrl` 获取。仅当 Electron 明确返回 `ERR_BLOCKED_BY_CLIENT` 时，图片才回退到桌面端 Node HTTP(S)；网络连接被重置时最多重试一次。下载后的正文使用本地图片内链，日后打开笔记不会为成功保存的图片再次访问原站。
